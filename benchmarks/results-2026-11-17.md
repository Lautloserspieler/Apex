# Apex Benchmark Results – 2026-11-17

**Note:** These benchmarks reflect the state of Apex at the end of the phase that was implemented up to this point (minimal inference core + real GGUF support via llama.cpp backend). They serve as the baseline for subsequent optimization phases.

Hardware: NVIDIA GeForce RTX 5070 (12 GB), CUDA 13.4  
Models: Qwen2.5 Instruct (Q4_K_M)  
Context: 2048–4096, max tokens: 256, temperature: 0  
Binary: Apex CUDA build with llama.cpp backend

## Summary

| Model   | Device | Load (s) | TTFT (s) | Prefill (tok/s) | Decode (tok/s) |
|---------|--------|----------|----------|-----------------|----------------|
| 0.5B    | GPU    | 0.257    | 0.052    | 157             | 690            |
| 3B      | GPU    | 0.469    | 0.062    | 1211            | 239            |
| 7B      | GPU    | 0.769    | 0.070    | 1082            | 123            |
| 3B      | CPU    | 0.882    | 0.834    | 89              | 24             |
| 7B      | CPU    | 1.885    | 1.907    | 39              | 11             |

## Notes

- GPU offloading worked fully for 3B (37/37 layers) and 7B (29/29 layers).
- Prefill performance on the RTX 5070 is strong.
- Decode throughput scales roughly as expected with model size.
- Flash Attention was reported as not supported and fell back (potential future optimization).
- TinyStories (656K) achieved ~9800 tok/s decode on GPU (expected for such a small model).
